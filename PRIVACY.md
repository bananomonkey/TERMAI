# Политика конфиденциальности TERMAI

Дата обновления: 19 октября 2026 г.

TERMAI — учебный тренажёр с ИИ-наставником. Приложение работает локально,
а Google-синхронизация включается только по желанию пользователя.

## Какие данные обрабатываются

- **API-ключ ИИ-провайдера.** Хранится только в локальных настройках
  приложения на устройстве и не передаётся разработчику.
- **Учебный прогресс.** По умолчанию хранится в локальном JSON-файле:
  решённые задачи, XP, серия, закладки, достижения, чаты с ментором.
- **Google-аккаунт (только при включённой синхронизации).** После входа
  через Google приложение получает `uid` и email аккаунта. В Cloud Firestore
  сохраняется документ `users_progress/{uid}`: прогресс, чаты, email и время
  последнего сохранения.
- **Запросы к ИИ.** Текст задачи, вопрос ментору и учебный контекст
  отправляются выбранному пользователем провайдеру ИИ (DeepSeek, OpenAI,
  Gemini и др.). Политика провайдера применяется к этим запросам.

## Общий бесплатный доступ TERMAI (акция)

Во время промо-акции в приложении может быть включён общий доступ к ИИ за
счёт TERMAI. Что важно знать:

- Запросы идут не напрямую к модели, а через серверный шлюз TERMAI на базе
  Token Harbor. Ключ Token Harbor хранится только на сервере и не попадает в
  APK, Flutter-код, Firebase Remote Config или Firestore.
- Перед первым запросом приложение показывает предупреждение и спрашивает
  согласие. Без согласия запросы через общий шлюз не отправляются.
- Для защиты шлюза от злоупотреблений общий доступ доступен только
  пользователям, вошедшим через Google. Приложение отправляет Firebase ID
  token, а сервер принимает только входы с провайдером `google.com`.
  Анонимные сессии не используются.
- Текст запросов обрабатывается Token Harbor и выбранной моделью по их
  правилам. Не отправляйте в чат секреты и персональные данные.
- Срок акции — единый для всех, задаётся на сервере. После окончания
  приложение автоматически возвращается к личному API-ключу пользователя.
- Пользователь может в любой момент выключить общий доступ в настройках и
  пользоваться только своим провайдером.

Приложение **не содержит рекламы, аналитики и трекеров**.

## Где хранятся данные

- Локально — в папке приложения на устройстве.
- В облаке — только если пользователь вошёл через Google и включил
  синхронизацию. Данные доступны только владельцу документа по правилам
  Firestore.

## Удаление данных

- Выйти из Google-аккаунта можно в настройках приложения.
- Кнопка **«Удалить облачные данные»** в настройках удаляет документ
  `users_progress/{uid}` из Firestore.
- Удаление приложения очищает локальные настройки и прогресс.
- Удалить аккаунт Google можно в настройках самого Google-аккаунта.

## Дети

Приложение предназначено для пользователей 13 лет и старше. Оно не
собирает данные о детях младше 13 лет.
