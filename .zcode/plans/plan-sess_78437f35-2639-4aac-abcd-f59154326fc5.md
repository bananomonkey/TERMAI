## 6. Блокнот с ИИ (реализуем)
Концепция: личные заметки + ИИ-ассистент письма. Для английского курса это и есть «практика написания текста»: черновик → «Проверить мой английский» → исправленный вариант с объяснениями.
- `lib/models.dart`: класс `Note {id, title, text, updatedAt}`; список `notes` в Progress (JSON `notes`), синхронизируется с облаком автоматически (Progress уже синхронизируется целиком).
- `lib/ai.dart`: `Future<String> noteAction(String action, String title, String text, {String? extra})` — один промпт, action ∈ {check_en, translate, improve, continue_text}; возвращает готовый текст результата.
- `lib/ui/notes_screen.dart` (новый): список заметок (title + превью + дата), FAB «Новая заметка»; экран заметки: TextField заголовка + многострочный текст + ряд кнопок ИИ («Проверить английский», «Перевести», «Улучшить», «Продолжить»); результат показывается в диалоге с кнопками «Заменить текст» / «Вставить ниже» / «Скопировать»; сохранение автосохранением при выходе.
- Меню «Ещё» (`lib/ui/more.dart`): пункт «Блокнот».

## 7. Рассылка новостей (бесп服务器ный вариант)
Схема: файл `announcements.json` в корне репо (рядом с README). Приложение читает его через raw.githubusercontent.com (как UpdateService читает GitHub API).
- Файл `announcements.json`: `[{"id": "news-1", "title": "...", "body": "...", "active": true}]`.
- `lib/update_service.dart` (+`AnnouncementInfo`): `fetchAnnouncement()` — GET raw URL, парсинг, возврат первой active. Обновить в `store.checkUpdates` (тот же троттлинг 6ч): `controller.announcement`; в Config — `lastAnnouncementId` (JSON `last_announcement_id`) для «показать один раз».
- `lib/ui/announce_banner.dart` (по образцу `update_banner.dart`): карточка title+body на главном (home.dart после UpdateBanner), кнопка «Понятно» → запоминает id.
- `lib/notifications.dart`: `showAnnouncement(title, body)` — мгновенное уведомление, id 1002, канал 'news' (копия showUpdate).
- `lib/update_background.dart`: при фоновой проверке тоже показать уведомление (gated как updatesNotifications).
- Как «присылать»: пользователь говорит новость в чате → правится announcements.json + коммит → через ≤6ч все увидят баннер, в фоне — уведомление.
