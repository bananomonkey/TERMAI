# Политика конфиденциальности TERMAI

Дата последнего обновления: 2026-11-08

TERMAI («приложение») уважает твою приватность и собран минимум данных,
необходимый для работы функций приложения.

## Какие данные обрабатываются

**Хранится только на устройстве (никогда не покидает телефон):**
- прогресс обучения, XP, статистика;
- заметки блокнота (файл на устройстве, в облако не отправляются);
- локальные черновики и буферы терминала.

**Отправляется в облако только по твоему явному действию:**
- Если ты входишь через Google и включаешь синхронизацию, прогресс и настройки
  сохраняются в Firebase (Google) в документ, привязанный к твоему аккаунту.
  Ключи ИИ синхронизируются только при включённом тумблере «Синхронизировать
  ключи ИИ в облако» (по умолчанию выключен).
- Ты можешь удалить облачную копию в любой момент: Настройки → Облачная
  синхронизация → Удалить облачные данные.

**Данные, передаваемые ИИ-провайдерам:**
- Запросы к ИИ (вопросы наставнику, тексты проверяемых работ, состояние
  учебной песочницы) отправляются провайдеру выбранной модели (например,
  z.ai, DeepSeek, OpenAI) или через пул бесплатных ключей приложения.
  Не отправляй в чаты и заметки, проверяемые ИИ, персональные данные и
  конфиденциальную информацию.

**Собирается автоматически:**
- агрегированный расход токенов (числа запросов/токенов — только локально,
  для отображения расхода тебе).

## Что приложение НЕ делает

- Не собирает контакты, геолокацию, идентификаторы рекламы.
- Не передаёт данные третьим лицам для рекламы или трекинга.
- Не требует регистрацию для базовой работы.

## Сторонние сервисы

- Firebase (Google LLC) — облачная синхронизация по желанию пользователя.
  Политика Google: https://policies.google.com/privacy
- ИИ-провайдеры — обрабатывают отправленные тобой тексты запросов по их
  собственным политикам.
