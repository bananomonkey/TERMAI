# TERMAI — публикация в RuStore

## Что уже готово

- **AAB** собирается на CI в каждом релизе (`TERMAI.aab` в ассетах релиза) — RuStore принимает .aab и .apk.
- Подпись release-ключом: `mobile/android/app/termai-release.jks` (пароли в GitHub Secrets).
- Package name: `com.vlad.termai`.
- Политика конфиденциальности: `docs/privacy-policy.md` — нужно опубликовать по публичной ссылке
  (можно включить GitHub Pages: Settings → Pages → ветка main / папка docs; ссылка будет
  `https://bananomonkey.github.io/TERMAI/privacy-policy.html` — конвертируй md в html или оставь .md).

## Чеклист регистрации (RuStore Консоль → rustore.ru)

1. Зарегистрируй аккаунт разработчика (нужны: ИНН или самозанятость/юрлицо — RuStore
   требует подтверждения личности; для бесплатного приложения достаточно физлица-самозанятого).
2. «Создать приложение»:
   - Название: **TERMAI — тренажёр терминала**
   - Категория: Образование
   - Тип: Приложение
   - Платная/бесплатная: бесплатное
3. Загрузить `TERMAI.aab` из последнего релиза GitHub.
4. Заполнить описание (ниже — готовый текст).
5. Скриншоты (минимум 2, лучше 4–6, PNG/JPEG до 8 МБ):
   - главный экран с направлениями;
   - урок (слайд Терминал с командами);
   - чат с ментором;
   - инцидент-режим;
   - статистика/прогресс.
6. Иконка 512×512 — взять из `mobile/assets/icon/` (при необходимости отмасштабировать).
7. Политика конфиденциальности — вставить публичную ссылку.
8. Возрастной рейтинг: 3+ (нет контента 18+, нет покупок).
9. Отправить на модерацию (обычно 1–3 дня).

## Готовое описание

**Короткое (до 80 символов):**
Тренажёр терминала Linux, Docker, Git и Kubernetes с ИИ-наставником.

**Полное:**

TERMAI — практический тренажёр для будущих DevOps-инженеров и всех, кто хочет
уверенно чувствовать себя в терминале.

Что внутри:
• Песочница терминала: Linux, Docker, Git, Kubernetes — команды выполняются
  прямо в приложении, ломать ничего не страшно.
• ИИ-наставник: объяснит ошибку, подскажет направление, проверит письменные
  работы (английский — от A1).
• Практика вместо теории: каждая задача проверяется по состоянию песочницы,
  а не «на глаз».
• Инцидент-режим: сломанная «продукция» — диагностируй и почини, как в
  настоящем дежурстве.
• Направления: DevOps, английский, Go — или создай своё, курс соберёт ИИ.
• Блокнот с ИИ-помощью: конспекты и черновики, улучшение текста одной кнопкой.
• Прогресс, XP, серия занятий, офлайн-режим базовых задач.

Бесплатный ИИ включён по умолчанию; свой API-ключ подключается в настройках.

## После модерации

- Обновления: тег в GitHub → CI собирает новый AAB → загрузить в RuStore
  (RuStore не умеет автообновление из GitHub — апдейтер приложения покажет
  баннер, но ставить новую версию надо из консоли RuStore).
- Держи версию в `mobile/pubspec.yaml` синхронной с тегом релиза.
