# TERMAI

Мобильный тренажёр терминала Linux/Docker с ИИ-наставником. Flutter (Dart).

## Что внутри

- **Курсы-тропинки**: Linux, Docker, Git — задачи генерирует ИИ по программе курса (минимум 5 на курс)
- **Слайды урока**: Справка с поиском · Задача · Терминал · Решение (скрыто до удержания кнопки)
- **Симулятор терминала**: базовые команды (ls, cat, cd, git, docker ps/images/rm…) работают мгновенно и оффлайн, остальное исполняет ИИ-симулятор
- **Ментор**: чат с ИИ по задаче, режим «Собеседование»
- **Закладки** с интервальным повторением, **достижения**, XP и серии
- Ключ хранится только на устройстве; поддерживаются DeepSeek, OpenAI, Gemini, Qwen, OpenRouter, Groq, Mistral, GigaChat, YandexGPT, Ollama

## Сборка

```bash
cd mobile
flutter pub get
flutter build apk --release
```

Готовый APK — в [Releases](../../releases).

## Структура

```
mobile/lib          — приложение (Dart)
  store.dart        — контроллер: состояние, терминал, проверка задач
  sandbox.dart      — оффлайн-симулятор команд
  ai.dart           — клиенты ИИ-провайдеров и промпты
  ui/               — экраны (тропинка курсов, слайды урока, чат)
mobile/assets       — курсы (JSON), иконки
```
